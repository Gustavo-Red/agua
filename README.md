# 💧 Mensagem urgente

Um cartão interativo e divertido para lembrar alguém de beber água.

## 🌐 Acessar o site

👉 **https://gustavo-red.github.io/agua/**

## 🐶 Como funciona

- Toque na capa para abrir o cartão.
- Clique em **"Bebi! Me deixa em paz"** para ver uma chuva de gotas e uma resposta engraçada.
- Tente clicar em **"Não vou beber"**... boa sorte, ele foge. 😏
